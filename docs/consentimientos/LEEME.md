# Consentimientos informados — formatos base (Word)

Dejá acá los archivos de los consentimientos (los formatos base que se van a
precargar y luego quedan editables por cada clínica en Administración).

## Qué dejar aquí

- Los `.docx` tal cual (Opción C), **o**
- Exportados a `.htm` / `.html` (Word → Guardar como → "Página web, filtrada")
  para conservar títulos, negritas y listas (Opción A, más fiel).

## Nombre de archivo sugerido

Usá un nombre claro por consentimiento, por ejemplo:

- `01-consentimiento-general.docx`
- `02-exodoncia.docx`
- `03-endodoncia.docx`
- `04-implantes.docx`
- `05-ortodoncia.docx`
- `06-anestesia.docx`

## Variables (datos que se rellenan automáticamente)

No hace falta que las marques: al procesarlos identifico dónde va cada dato. Si
querés marcarlas tú, usá llaves, por ejemplo:

`{nombreCompleto}` `{rut}` (o `{documento}`) `{fechaNacimiento}` `{edad}`
`{sexo}` `{direccion}` `{telefono}` `{apoderado}` `{rutApoderado}` `{nFicha}`
`{clinicaNombre}` `{clinicaDireccion}` `{clinicaCiudad}` `{clinicaTelefono}`
`{fecha}` `{profesional}`  (el logo va en el encabezado automáticamente)

## Datos mínimos obligatorios (en todos)

Nombre completo, RUT/documento, fecha de nacimiento y edad. Cada formato puede
exigir datos adicionales según su contenido.
